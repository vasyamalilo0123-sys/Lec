# Прототип: фотореалістичний фрагмент у Blender (≈1 хв)

Той самий фрагмент «Бронхіальне дерево» (`lectures/bronchi`, сцена `01-tree`), але замість пласкої SVG-ілюстрації — тривимірна модель і фізично коректний рендер (Blender 5.3, Cycles). Текст диктора, голос, тези, підписи й джерела — ті самі, що в затвердженому фрагменті; голос узято з кешу `lectures/bronchi/audio/` без нового синтезу.

Результат: `blender-bronchi.mp4` (1920×1080, 25 кадрів/с, 60,8 с).

## Як зроблено

1. **Геометрія** — `build_geometry.py`. Жодних готових моделей: трахея, бронхи до субсегментарних і легені описані як неявні поверхні (поля відстаней) і перетворені на сітки (marching cubes, крок 0,3 мм для дихальних шляхів). Розміри — в `anatomy.json`, звірені з джерелами в `anatomy-facts.json`.
   - Трахея: 18 С-подібних хрящів, відкритих назад, пласка перетинчаста задня стінка, нахил дозаду.
   - Головні бронхи лежать в одній площині з трахеєю; правий — 25°, лівий — 45° від її осі (як у тексті диктора).
   - Часткові й сегментні бронхи B1–B10 з обох боків (зліва B1+2 і B7+8), хрящі — неправильні пластинки.
   - Легені: 3 частки справа (коса й горизонтальна щілини), 2 зліва, серцева вирізка, куполи діафрагми (правий вищий).
   - Друга сітка — фронтальний розтин трахеї й головних бронхів по трахеобронхіальній площині (видно зріз хрящів і слизову).
2. **Сцена** — `scene.py`: матеріали з підповерхневим розсіюванням (хрящ, адвентиція з судинним малюнком, слизова, плевра з часточковим малюнком), студійне світло на чорному тлі. Правило стилю збережено: те, про що мова, — у кольорі, решта сіра (атрибути вершин керують знебарвленням).
3. **Рендер** — `render_all.py`: 8 нерухомих станів (2112×1188, із запасом на повільне наближення), горошина в розтині (рендериться лише ділянка довкола неї), гачок (горошина великим планом).
4. **Накладення** — `overlay.html` + `overlay.js`: тексти Geologica, виноски, кути; на кожному кадрі автоматична перевірка «текст на тексті», «виноска на тексті», поля.
5. **Збирання** — `compose.py`: перехресні переходи станів, наближення, голос; час — з `lectures/bronchi/out/timing.json`.

```
pip install bpy scikit-image scipy pillow
node ../../kit/lecture.js ../../lectures/bronchi plan
python3 build_geometry.py out/geo 0.3
python3 render_all.py out/geo out/r
python3 timeline.py out/r/proj.json out/r/timeline.json
node overlay.js out/r/timeline.json out/ov
python3 compose.py out/r out/ov blender-bronchi.mp4
```

## Обмеження прототипу

- Машина без відеокарти (4 ядра): повнокадрова анімація камери в Cycles коштувала б десятки годин, тому рух — це переходи між відрендереними станами й повільне наближення; справжній 3D-рух лише в гачку та в польоті горошини.
- Форма легень і сегментних бронхів — параметрична, анатомічно правдоподібна, але не зліпок із КТ. Серце, судини, стравохід не показані.
- Кути 25° і 45° — класичні підручникові; КТ-морфометрія дає для правого бронха ≈35° (див. `anatomy-facts.json`). Якщо змінювати — разом із текстом диктора.
