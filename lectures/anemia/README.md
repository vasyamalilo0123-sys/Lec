# Анемія за одну хвилину — експеримент «кінематографічний фотореалізм»

Проба на прохання автора: не стиль «Атлас», а 3D у Blender (Cycles) плюс моушн-графіка. Порядок роботи взято зі скілів
[mromidev/claude-blender-skills](https://github.com/mromidev/claude-blender-skills) (`blender-film`): розкадровка → сцена кодом →
рух із фізики → пробні кадри малої якості → відновлюваний рендер кадрами PNG → звук від руху → перевірка кадрів.
Готових моделей і записів немає: клітини, судина, світло й звук побудовані кодом.

| Файл | Що робить |
|---|---|
| `script.json` | текст диктора, плани, джерела |
| `tts.py` → `audio/` | голос ElevenLabs із мітками символів (кеш, повторно не синтезує) |
| `plan.py` → `timeline.json` | розкладка хвилини за тривалістю реплік |
| `blender/build.py` | чотири сцени: `flow` (потік у судині, анемія настає в кадрі), `third` («кожна третя»), `sizes` (мікро-, нормо-, макроцит), `outro` |
| `blender/render.py`, `blender/render_all.sh` | пробні кадри й відновлюваний рендер у `render/` (не комітиться) |
| `overlay/render.js` | титри й цифри, прив'язані до слів диктора (прозорі PNG) |
| `sfx.py` | серцебиття (прискорюється з настанням анемії), гул кровотоку, зведення з голосом |
| `srt.py` → `anemia.srt` | субтитри з повним текстом |
| `assemble.py` → `anemia.mp4` | складання: 1080p, сяйво, контраст, віньєтка, зерно, титри, звук |

Запуск: `pip install bpy numpy`, далі `python tts.py && python plan.py && blender/render_all.sh && node overlay/render.js && python sfx.py && python srt.py && python assemble.py`.

Факти: пороги гемоглобіну — настанова ВООЗ 2024; поширеність 30,7 % жінок 15–49 років — ВООЗ GHO 2025 (дані 2023);
дефіцит заліза як найчастіша причина — ВООЗ, Anaemia fact sheet 2025; ≈ 2 млн еритроцитів на секунду — підручникова оцінка.
