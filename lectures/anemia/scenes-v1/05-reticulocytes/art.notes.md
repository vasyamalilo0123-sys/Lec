# 05-reticulocytes — art.svg

viewBox `0 0 900 1000` (під типове поле `art` 900×1000 праворуч). Генератор: власний скрипт, координати з одним знаком.
Компонування: угорі ліворуч кістка, праворуч судина, між ними дві стрілки (мало — вгорі, багато — внизу); унизу ліворуч збільшений ретикулоцит, праворуч рамка лічби.

## Групи (`parts`)

| id | що це | де підпис |
|---|---|---|
| `marrow` | поперечний переріз кістки: кортикальний шар з остеонами, червоний мозок із жировими клітинами, два живильні канали праворуч (виходи стрілок) | `a-marrow`, над кісткою або ліворуч у текстову колонку |
| `vessel` | відрізок судини (стінка, просвіт, зріз угорі, еритроцити всередині) | `a-vessel`, праворуч угорі від судини |
| `flow_low` | тонка бурштинова стрілка мозок → судина, дві поодинокі клітини над нею | `a-low` — вільне місце над стрілкою (y ≈ 60–150) |
| `flow_high` | товста стрілка з 13 клітинами + праворуч від судини ознаки втрати: крапля крові й розірвана клітина з уламками | `a-high` — під стрілкою (y ≈ 455–560); `a-loss` — над краплею |
| `retic` | збільшений ретикулоцит: плаский червоний диск зі світлішим центром | `a-retic`, ліворуч (лінія у текстову колонку) |
| `mesh` | синя сіточка залишків РНК поверх `retic` (окрема сусідня група, лежить вище) | `a-mesh`, підпис під диском (y > 910) або ліворуч |
| `counter` | рамка 10×10 = 100 еритроцитів, 6 позначено синім кільцем як ретикулоцити | `a-counter` — над рамкою (y ≈ 560–615) |

## Точки (`r="0"`)

| id | призначення |
|---|---|
| `a-marrow` `a-vessel` `a-retic` `a-mesh` `a-low` `a-high` `a-loss` `a-counter` | прив'язка підписів (див. вище) |
| `o-low`, `o-high` | початки росту стрілок (вихід живильних каналів кістки) |
| `o-retic` | центр ретикулоцита (ріст/поява з центру) |
| `o-counter` | лівий верхній кут рамки |

## Траєкторії

| id | що |
|---|---|
| `p-low` | вісь тонкої стрілки, кістка → стінка судини |
| `p-high` | вісь товстої стрілки, кістка → стінка судини |

## Числа
- Ретикулоцит Ø 256 проти дрібних еритроцитів Ø 25 — збільшення ≈ ×10.
- Рамка — рівно 100 клітин, позначено 6 (без числових порогів, f12).
- Ширина стрілок: 4 проти 34 (≈ ×8,5); клітин: 2 проти 13.
- Сіточка в межах r ≤ 102 від центру диска (r 128) — не виходить за контур.
