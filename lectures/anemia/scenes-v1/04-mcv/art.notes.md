# 04-mcv — art.svg

viewBox `0 0 900 900`. Еритроцити в одному масштабі: 25,3 px/мкм. Діаметри: micro 6,0 мкм (152 px), normo 7,5 мкм (190 px), macro овал 10,4×8,8 мкм (263×223 px, нахил −8°). Блідий центр: 62 % діаметра (micro, гіпохромний), 36 % (normo), 24 % (macro). Вісь лінійна, 60–120 фл → x 0–900 (15 px/фл): 80 фл → x 300, 100 фл → x 600; центри клітин збігаються з 70/90/110 фл (x 150/450/750). Розміри клітин — типові діаметри в мазку, а не масштаб за об'ємом.
