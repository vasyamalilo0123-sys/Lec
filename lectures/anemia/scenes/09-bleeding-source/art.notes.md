# 09-bleeding-source — art.svg

viewBox `0 0 900 1000`. Тулуб x 290–787, y 66–898. Вільне місце для підписів: ліворуч x 0–285 (уся висота), праворуч x 790–900, низ y 900–1000.
Порядок шарів: body → upper → lower → kidney → uterus → duod → drop. Нирки й сечоводи за кишкою: перекриті частини — тонким пунктиром (маска). `duod` лягає поверх `upper` і не заходить під шлунок.

## Групи (parts)

| id | що це | де ставити підпис |
|---|---|---|
| `body` | сірий силует тулуба, ключиці, діафрагма, реберна дуга, край печінки, пупок | не підписується |
| `upper` | стравохід, шлунок, дванадцятипала кишка (рожево-цегляні) | «Гастроскопія» — від `a_stomach` праворуч або від `a_eso` ліворуч |
| `lower` | товста кишка від сліпої з апендиксом до прямої, гаустри | «Колоноскопія» — від `a_colon_asc` ліворуч |
| `kidney` | нирки, сечоводи, сечовий міхур (блідо) | «Аналіз сечі на кров» — від `a_bladder` або `a_kidney_r` ліворуч |
| `uterus` | матка, труби, яєчники | «Менструальні втрати» — від `a_uterus` ліворуч, низ y≈720–800 |
| `duod` | окремо дванадцятипала кишка з трьома місцями біопсії | «Целіакія: серологія або біопсія» — від `a_biopsy` ліворуч |
| `drop` | значок краплі крові біля низхідної ободової кишки | без підпису або від `a_drop` праворуч |
