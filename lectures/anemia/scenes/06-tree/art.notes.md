## Групи (parts), порядок малювання

| id | Що це | Колір |
|---|---|---|
| `root` | плашка «Анемія» з краплею, наполовину порожньою, + стовбур донизу | темно-бура, крапля червона |
| `br_mic` | з'єднання від стовбура + плашка з дрібним блідим еритроцитом | блідо-червоний `#e9a397` |
| `leaf_mic` | хребет колонки й три листки: ЗДА (порожнє кільце), запалення (полум'я), таласемія (мішеневидна клітина) | блідо-червоний |
| `br_nor` | з'єднання + плашка зі звичайним еритроцитом | червоний `#d1453b` |
| `br_nlow` | відгалуження, плашка «ретикулоцити ↓» (один ретикулоцит) + три листки: нирка, полум'я, кістка | червоний |
| `br_nhigh` | довге відгалуження (накриває хребет `br_nlow`), плашка «ретикулоцити ↑» (сім ретикулоцитів) + два листки: крапля, розірвана клітина | червоний |
| `br_mac` | з'єднання + плашка з великим овальним еритроцитом | бордовий `#8c2233` |
| `leaf_mac` | хребет і два листки: мегалобластна (гіперсегментоване ядро нейтрофіла), немегалобластна (великий макроцит) | бордовий |

Розміри значків еритроцитів (rx 11 : 15 : 20 = 0,73 : 1 : 1,33) свідомо перебільшено. Справжні відмінності діаметра за MCV 70/90/110 фл (корінь кубічний) — лише 0,92 : 1 : 1,07, на око майже непомітні.
