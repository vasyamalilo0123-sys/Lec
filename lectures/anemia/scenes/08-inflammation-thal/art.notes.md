# 08-inflammation-thal — art.svg

viewBox `0 0 1000 1000`. Ліворуч (x 20–490) — схема гепцидину, праворуч (x 550–985) — мазки й електрофорез. Вільне місце для підписів: смуга y 0–100 над усім, x 280–480 / y 300–540 (праворуч від стрілки), x 500–990 / y 160–245 (над мазками), y 800–1000 по всій ширині.

## Групи (`parts`)

| id | що це | де ставити підпис |
|---|---|---|
| `liver` | печінка спереду (права частка ліворуч), серпоподібна зв'язка, дно жовчного міхура | над печінкою від `a_liver` |
| `macro` | макрофаг: ядро, вакуоля з поглинутим еритроцитом, ~30 крапок заліза, феропортин на правій мембрані | під клітиною від `a_macro` |
| `gut` | ентероцит: щіткова облямівка праворуч (просвіт кишки), ядро біля базальної мембрани, залізо в цитоплазмі, феропортин на базолатеральній (лівій) мембрані | під клітиною від `a_gut` |
| `hep` | салатова стрілка-сигнал від печінки, що розходиться до обох феропортинів, + 3 молекули-«шпильки» гепцидину | праворуч від стрілки від `a_hep` |
| `lock` | гепцидин сидить у порі обох феропортинів + засувка біля кожних «дверей» | униз від `a_lock` (y ≈ 830), між клітинами |
| `smear_ida` | поле мазка ЗДА: 19 блідих дрібних клітин різного розміру (сер. діаметр 23,1), один олівцеподібний | над полем від `a_ida` |
| `smear_thal` | поле мазка носійства таласемії: 60 дуже дрібних щільних клітин (сер. діаметр 16,2), 12 мішеневидних | над полем від `a_thal` |
| `ep` | смужка електрофорезу (лужний, катод «−» ліворуч, анод «+» праворуч), лінія нанесення пунктиром; верхня доріжка — норма зі слабкою A2, нижня — носій (лише смуга HbA) | під смужкою від `a_ep`; назви доріжок ліворуч від `a_lane_norm`, `a_lane_carrier` (місця ліворуч мало — підпис коротко, або над смужкою) |
| `a2` | посилена смуга HbA2 у доріжці носія + жовта рамка виділення | під рамкою від `a_a2` (y ≈ 800+) |
