# Наголоси в тексті диктора: статус перевірки

Статус: підтверджених за словниками наголосів немає; у `scene.json` нічого не змінено.
Причина: сайти словників (sum.in.ua, goroh.pp.ua, uk.wiktionary.org; lcorp.ulif.org.ua і slovnyk.ua без відповіді) недоступні із середовища сесії (мережа блокує хости, WebFetch: ENOTFOUND, curl: 403 на CONNECT). WebSearch повертає лише стислі переказні відповіді без самих словникових статей; такі відповіді не вважаю джерелом (напр. для «гемоліз» переказ дав ГЕМО́ЛІЗ, що суперечить загальновідомому гемолі́з, тобто переказу довіряти не можна).
