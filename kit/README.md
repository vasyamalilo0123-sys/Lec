# Набір для варіантів відеолекції

Спільний рушій грає один і той самий 26-секундний фрагмент («Вінцеві артерії») у різних стилях.
Зміст, тексти й хронометраж зашиті в рушій і не змінюються. Варіант задає лише стиль — трьома файлами.

## Що робить варіант

Тека `variants/<назва>/`:

| Файл | Що в ньому |
|---|---|
| `art.svg` | Власна ілюстрація серця спереду. Малюється з нуля під стиль. |
| `style.json` | Шрифти, місце малюнка в кадрі, позиції підписів, вигляд виносок, параметри руху. |
| `style.css` | Типографіка й розміщення заголовка, тези та службових рядків. |

Готові чи запозичені зображення заборонені. Референс у `kit/ref/` — лише для пропорцій і ходу судин.

## Контракт `art.svg`

- Кореневий `<svg viewBox="…">` довільного розміру, без `width`/`height`, без `<style>` із глобальними селекторами, без зовнішніх посилань, растрових зображень і фільтрів розмиття.
- Обов'язкові групи:
  - `<g id="tissue">` — усе, крім вінцевих артерій (камери, великі судини, борозни, деталі);
  - `<g id="rca">` — права вінцева артерія з гілками;
  - `<g id="lca">` — стовбур лівої вінцевої артерії;
  - `<g id="lad">` — передня міжшлуночкова гілка з її гілками;
  - `<g id="lcx">` — огинальна гілка.
  Частини артерій, що проходять позаду інших структур, малюються в тих самих групах пунктиром або тоншою лінією.
- Обов'язкові точки (кола з `r="0"`, координати у системі viewBox):
  - прив'язки підписів: `a-aorta`, `a-rv`, `a-lv`, `a-rca`, `a-lca`, `a-lad`, `a-lcx` — точка на самій структурі;
  - місця відходження артерій: `o-rca`, `o-left` — від них рушій «вирощує» артерії.
- Групи артерій мають бути сусідами на одному рівні (не вкладати одну в одну) і стояти після `#tissue`.
- Обсяг файлу — до 30 КБ. Координати з одним знаком після коми.

## `style.json`

```json
{
  "name": "Назва стилю",
  "fontCss": ["fonts/fixel.css", "node_modules/@fontsource/jost/600.css"],
  "art": {"x": 930, "y": 110, "w": 640, "h": 860},
  "labels": {
    "aorta": {"x": 1500, "y": 150, "align": "left"},
    "rv": {"x": 1258, "y": 548, "align": "center", "onArt": true},
    "lv": {"x": 1412, "y": 640, "align": "center", "onArt": true},
    "rca": {"x": 900, "y": 560, "align": "right"},
    "lca": {"x": 1500, "y": 300, "align": "left"},
    "lad": {"x": 1560, "y": 720, "align": "left"},
    "lcx": {"x": 1560, "y": 520, "align": "left"}
  },
  "leader": {"type": "straight", "width": 1.6, "color": "#f4f1ee", "marker": "ring", "gap": 14},
  "motion": {"text": "wipe", "dimTissue": 0.36, "dimOther": 0.3}
}
```

- Кадр 1920 × 1080, координати в пікселях кадру. `x` — лівий край тексту для `left`, правий для `right`, середина для `center`; `y` — верх блоку.
- `onArt: true` — підпис лежить просто на малюнку, без виноски. `leader: false` — підпис без виноски. `sub: false` — без пояснювального рядка (є в `lad` і `lcx`).
- `attach` (`left` / `right` / `top` / `bottom`) — з якого боку тексту виходить виноска; типово з боку вирівнювання.
- `leader.type`: `straight` або `elbow`; `marker`: `ring`, `dot`, `none`; також `opacity`, `markerSize`, `markerFill`, `elbow`.
- `motion.text`: `wipe` або `fade`; `dimTissue` — яскравість тканин, коли мова про артерії; `dimOther` — яскравість артерій поза фокусом.
- `fontCss` — шляхи від теки `kit/`. Fixel: `fonts/fixel.css` (родини `Fixel Display` і `Fixel Text`, 300–900). Інші: `node_modules/@fontsource/<пакет>/<вага>.css`, родина називається як на Google Fonts.
  Доступні пакети: sofia-sans, sofia-sans-condensed, sofia-sans-extra-condensed, jost, unbounded, geologica, montserrat, mulish, nunito, oswald, commissioner, wix-madefor-display, tektur, comfortaa, exo-2, raleway, jetbrains-mono, martian-mono. Нових пакетів не встановлювати.

## `style.css`

Стилізуються: `#stage`, `#kicker` (назва лекції), `#title` (заголовок розділу), `#thesis` (одна коротка теза), `#credit`, `.lab` (підпис), `.lab small` (пояснення), `.onart` (підпис на малюнку), окремі підписи `.l-aorta`, `.l-rv`, `.l-lv`, `.l-rca`, `.l-lca`, `.l-lad`, `.l-lcx`.
Позиції `#kicker`, `#title`, `#thesis`, `#credit` задаються через `left`/`top` (вони `position:absolute`). Довгий підпис можна переносити: `.l-lad{white-space:normal;width:320px}`.

## Хронометраж фрагмента

| Час, с | Що в кадрі |
|---|---|
| 0–2,6 | Заголовок розділу на чорному |
| 2,6–7,4 | З'являється серце (артерій ще немає); підписи: аорта (4,0), правий шлуночок (5,2), лівий шлуночок (6,2) |
| 7,4–8,5 | Заголовок і ці підписи зникають, тканини приглушуються |
| 8,6–12,6 | Ростуть права, потім ліва артерія; підписи обох |
| 13,0–15,6 | Теза «Обидві починаються від кореня аорти» |
| 16,2–19,2 | У фокусі передня міжшлуночкова гілка, решта артерій приглушена |
| 19,8–22,2 | У фокусі огинальна гілка |
| 22,6–25,4 | Усі артерії яскраві, три підписи, теза «Ліва артерія дає дві гілки, права — одну» |

Заголовок розділу видно одночасно з малюнком і першими підписами (2,6–7,4 с) — вони не повинні накладатися.

## Команди

```sh
node kit/render.js variants/<назва> qa          # перевірка + аркуш із 7 кадрів: variants/<назва>/out/sheet.jpg
node kit/render.js variants/<назва> still 18.6  # один кадр у повному розмірі
node kit/render.js variants/<назва> video       # variants/<назва>/out/<назва>.mp4
```

`qa` завершується з кодом 0 лише коли немає жодного зауваження. Перевіряється:
текст у межах полів кадру; мінімальні розміри (підпис 30 px, пояснення 26 px, теза 36 px, підпис на малюнку 28 px);
накладання текстів; виноска крізь будь-який текст; перетин виносок; виноска довша за 520 px; контраст тексту з тлом під ним.

## Правила стилю, спільні для всіх варіантів

Повний текст — `docs/style-guide.md`. Коротко:

- Фон чорний `#000`. Усе пласке, 2D: жодних тіней, відблисків, об'ємного тонування, світіння, розмиття.
- Жодних шрифтів із засічками. Жодної «крейди». Жодних крапок-частинок.
- Нічого декоративного: кожен елемент малюнка щось пояснює або потрібен для впізнаваності.
- Підпис стоїть поруч зі своєю структурою; виноска коротка й не перетинає ні текст, ні іншу виноску.
- Мало тексту: у кадрі одночасно заголовок або одна теза плюс підписи.
- Заборонені шаблонні прийоми: великі літери з розрядкою як «надзаголовок», переліки через «·», кольорова смужка збоку від тексту, декоративні номери, тонкі смужки прогресу, сірий текст низького контрасту, усе по центру.
- Малюнок має виглядати зробленим рукою художника: продумана товщина лінії, характер форми, деталі (борозни, вушка, зрізи судин), а не згладжений автоматичний силует.
