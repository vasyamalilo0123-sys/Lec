# Правила стилю відеолекцій

Робоча версія. Кожне правило виведене з досліджень навчання з відео; джерела — внизу.
Розміри вказано для кадру 1920×1080.

## 1. Що є в кадрі

| Правило | Що це означає на практиці | Підстава |
|---|---|---|
| Нічого зайвого | Жодних декоративних фактур, орнаментів, фонової музики, «красивих» деталей, які не пояснюють тему | Принцип узгодженості; метааналіз «спокусливих деталей» (58 досліджень) |
| Підпис біля об'єкта | Назва стоїть поруч зі структурою і має її колір. Легенди з номерами не використовуємо | Просторова суміжність, g ≈ 0,63; кольорове кодування (Ozcelik, 2009) |
| Елемент з'являється, коли про нього говорять | Схема будується частинами в такт диктору, а не показується готовою | Часова суміжність; принцип динамічного малювання |
| Одне у фокусі | Те, про що йдеться зараз, яскраве; решта приглушена до ~30 % | Сигналізація, d ≈ 0,38–0,46 |
| Показане лишається | Попередні кроки не зникають: кадр накопичується, у фіналі видно всю тему | Ефект минущої інформації |
| Спершу частини, потім процес | Перед поясненням механізму називаємо структури, які в ньому беруть участь | Попереднє навчання |
| Текст — лише ключове | На екрані терміни, цифри й коротка теза (до ~8 слів). Повний текст диктора — у файлі субтитрів, не в кадрі | Надлишковість; виняток для термінів |
| Короткі розділи | Розділ до ~6 хвилин; угорі видно, де ми зараз | Сегментування; Guo et al., 2014 |
| Пауза на пригадування | Наприкінці розділу — одне запитання на 5 секунд, потім відповідь | Вбудовані запитання (докази неоднорідні, тому помірно) |

## 2. Ілюстрація

- Ілюстрації малюють власні художники-помічники з нуля, кодом SVG. Готові зображення з інтернету не використовуємо; анатомічна 3D-модель — лише орієнтир пропорцій.
- Мова малюнка «Атлас»: упевнений світлий контур двох товщин (силует товщий, внутрішні межі тонші), пласкі анатомічні кольори, деталі рукою художника. Без тіней, відблисків, градієнтів, розмиття.
- **Колір = предмет розмови.** Об'єкт уперше з'являється в кольорі. Коли мова переходить далі, він стає сірим (знебарвлення й затемнення), а в кольорі лишається тільки те, про що йдеться зараз. У підсумку кольорові всі структури, про які йшлося.
- Підпис структури видно, лише поки вона в кольорі.
- Приховану частину структури показуємо пунктиром того самого кольору.

## 3. Колір

- Фон чорний `#000`, текст теплий білий, другорядний — той самий колір із прозорістю не нижче 62 %.
- Кольори структур — анатомічна традиція: артерії червоні, вени сині, дихальні шляхи блакитні, тканини органів приглушені.
- Підписи білі на чорному або на сірому малюнку; на кольоровій поверхні органа — темним чорнилом.
- Контраст тексту з тлом не нижче 4,5:1 (великого тексту — 3:1); це перевіряється автоматично. Колір ніколи не єдиний носій значення: поруч завжди підпис.

## 4. Типографіка

- Гарнітура Geologica, легкі накреслення (200–400), без засічок.
- Розміри: гачок і заголовок розділу від 100 px, теза 48–56 px, підпис структури 34–38 px, пояснення 26–28 px.
- У кадрі одночасно: заголовок або одна теза плюс підписи. Службові рядки — звичайним реченням.

## 5. Рух

Рух має значення і не повторюється механічно.

- Текст розкривається зліва направо, як під час читання (≈0,5 с).
- Виноска росте від структури до підпису, потім розкривається підпис.
- Артерія «росте» від місця відходження (1,5–1,7 с).
- Зміна фокуса — це зміна яскравості, без переміщень.
- Однакового «виїзду знизу» на всіх елементах, пружинних і підстрибувальних рухів немає.

## 6. Звук

- Голос диктора — основний канал пояснення, тон розмовний.
- Фонової музики під голосом немає. Окремі короткі звуки допустимі лише як сигнал події.

## 7. Чого не робимо: ознаки «ШІ-дизайну»

За каталогом avoid-ai-design і власним розбором попередніх версій:

| Ознака | Замість цього |
|---|---|
| Inter або інший шрифт «за замовчуванням» на все | Обрана гарнітура з виразною ієрархією |
| Великі літери з розрядкою над кожним блоком | Звичайне речення або нічого |
| Перелік через крапку посередині «А · Б · В» | Звичайна фраза з комами |
| Кольорова смужка збоку від тексту | Розмір, насиченість, положення |
| Тонований «майже чорний» фон із сірим текстом | Чорний фон і чіткий світлий текст |
| Рівномірна «обережна» палітра пастельних акцентів | Колір із самого предмета, один домінує |
| Усе по центру | Асиметрична сітка: конспект ліворуч, малюнок праворуч |
| Декоративні номери 01 / 02 / 03, тонкі смужки прогресу | Номер лише там, де справді є послідовність |
| Однакове «проявлення зі зсувом» на всіх елементах | Рух за змістом (розділ 5) |
| Згенерована безлика графіка | Ілюстрація, зроблена людиною-фахівцем |
